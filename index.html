Cài đặt môi trường C++ thi đấu
chỉ với một dòng lệnh

Chuẩn mặc định C++17 (-std=c++17 -O2). Tự động nhận diện hệ điều hành và kiến trúc 32/64-bit, cài đặt đầy đủ g++, gdb và IDE chuẩn cấu hình trên Windows, Linux và macOS.

Nhánh /cb — Code::Blocks + g++ + gdb (C++17)
curl -fsSL https://raw.githubusercontent.com/PTK-2411/cpsetup/main/cb/auto | bash
  • Hỗ trợ Ubuntu/Debian (.deb), Fedora/RHEL/openSUSE (.rpm), Arch/Manjaro (.tar.gz) cho cả 32-bit và 64-bit.
  • Tải trước toàn bộ gói với cơ chế retry khi mạng chập chờn; tự kiểm tra và sửa cấu hình Code::Blocks sang -std=c++17 -O2.
  • Sau khi cài xong, gõ cb để mở Code::Blocks tách biệt khỏi terminal (tắt terminal không làm tắt IDE), hoặc cpsetup-cb-check để kiểm chứng.
curl -fsSL https://raw.githubusercontent.com/PTK-2411/cpsetup/main/cb/auto | bash
curl -fsSL https://raw.githubusercontent.com/PTK-2411/cpsetup/main/cb/mac64.sh | bash
curl -fsSL https://raw.githubusercontent.com/PTK-2411/cpsetup/main/cb/macarm64.sh | bash
  • Yêu cầu đã cài sẵn Homebrew.
  • Cài đặt GNU GCC (g++-14 / g++-15) thay vì Apple Clang mặc định để tương thích chuẩn bài thi đấu.
curl -fSL https://raw.githubusercontent.com/PTK-2411/cpsetup/main/cb/auto.bat -o cpsetup-cb.bat && cpsetup-cb.bat
  • Mở Command Prompt (cmd) và dán lệnh trên để chạy.
  • Tự nhận diện Windows 32-bit (win32) hoặc 64-bit (win64), hỗ trợ tải resume (-C -) nếu rớt mạng giữa chừng.
  • Kiểm tra sẵn g++ và Code::Blocks nếu máy đã cài trước đó, tránh cài trùng lặp.

Các nhánh công cụ trong Competitive Programming Setup

/cb Sẵn sàng

Code::Blocks + C++17

Bộ cài đầy đủ Code::Blocks, g++, gdb kèm cấu hình chuẩn -std=c++17 -O2 và lệnh mở nhanh cb.

/cpp Sắp ra mắt

Chỉ Toolchain C++

Cài gọn nhẹ g++, gdb và build tools chuẩn C++17, không kèm IDE nặng.

/vs Sắp ra mắt

VS Code + C++17

Visual Studio Code kèm toolchain C++ và bộ cấu hình/extension cơ bản cho lập trình thi đấu.

/rs Định hướng sau

Rust CP IDE

Môi trường IDE viết bằng Rust tối ưu tốc độ cho học sinh và người dùng nâng cao.
